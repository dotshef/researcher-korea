## Cross-Platform Summary

## Key Insights

### 1. SaaS 플랫폼 신규 구축 (Score: 73)
4건의 프로젝트가 위시켓과 프리모아에서 수집되었으며, 공통적으로 "특정 산업에 맞는 SaaS가 없어서 직접 만든다"는 패턴이 뚜렷하다. 쿠팡 셀러 통합관리(5,000~8,000만원)는 이커머스 운영 효율화, SaaS 마켓플레이스는 B2B SaaS 유통, 금형산업 시스템은 제조업 디지털화, 병원 SaaS(2,000~4,000만원)는 헬스케어 데이터 관리를 각각 해결하려 한다. 특히 프리모아의 병원 SaaS는 고객이 이미 확보된 상태로, 시장 수요가 검증된 케이스이다. 이 클러스터는 "범용 SaaS의 한계 → 버티컬 SaaS의 기회"라는 구조적 트렌드를 보여준다.
- 예산 범위: 2,000만~8,000만원
- 제품 기회: 버티컬 SaaS 빌더 — 산업별 맞춤 SaaS를 빠르게 구축할 수 있는 로우코드/노코드 플랫폼. 또는 각 버티컬(이커머스 셀러, 제조업, 헬스케어)에 직접 진입하는 SaaS 제품.
- 관련 소스:
  - [쿠팡 셀러용 통합 관리 SaaS 플랫폼 구축](https://www.wishket.com/project/144987/) — 위시켓
  - [SaaS 개발사/구매자 중개 플랫폼 구축](https://www.wishket.com/project/140253/) — 위시켓
  - [클라우드 기반 SaaS 시스템 관리자 웹 페이지 및 서버 구축](https://www.wishket.com/project/116575/) — 위시켓
  - [병원 데이터 통계 SaaS 웹서비스 개발 (월 구독형 서비스)](https://www.freemoa.net/m4/s41?pno=47928) — 프리모아

### 2. 기존 SaaS 개선/운영 (Score: 30)
3건 전량이 위시켓에서 수집되었다. AWS 인프라 비용 절감, 커머스 SaaS API 확장, 레거시(MSSQL+ASP) 유지보수로, SaaS 제품이 성장기를 지나 "운영 비용 최적화"와 "기능 고도화"가 필요한 단계의 문제들이다. 예산이 명시되지 않았지만, 이러한 유지보수/개선 프로젝트는 반복적으로 발생하는 특성이 있어 구독형 DevOps/인프라 최적화 서비스의 기회가 존재한다.
- 제품 기회: SaaS 운영 비용 최적화 자동화 도구 (AWS 비용 모니터링, 성능 병목 진단)
- 관련 소스:
  - [인프라 비용 절감을 위한 AWS 아키텍처 다운사이징 및 Java 백엔드 경량화](https://www.wishket.com/project/152055/) — 위시켓
  - [SaaS 형 커머스 서비스 API 개선 및 신규 기능 구현](https://www.wishket.com/project/104632/) — 위시켓
  - [MSSQL + Classic ASP 개발 및 유지보수](https://www.wishket.com/project/131519/) — 위시켓

### 3. AI/특화 SaaS 프론트엔드 (Score: 27)
B2B 업무관리 툴(위시켓), LLM 기반 서비스(위시켓), 자율주행 SaaS(원티드긱스)의 프론트엔드/디자인 수요 3건이다. 공통적으로 "서비스 로직은 있는데 사용자 인터페이스가 부족"한 패턴이며, 초기 스타트업부터 자율주행 전문기업까지 다양한 규모에서 동일한 문제를 겪고 있다.
- 제품 기회: SaaS UI 킷 / 프론트엔드 컴포넌트 라이브러리 (대시보드, 데이터 시각화, B2B 패턴 특화)
- 관련 소스:

  - [LLM 기반 서비스 Frontend 개발](https://www.wishket.com/project/133048/) — 위시켓

## Action Items
1. **즉시 검증 가능**: 이커머스 셀러 관리 SaaS — 쿠팡 셀러용 통합관리 플랫폼(5,000~8,000만원) 수요가 확인됨. 셀러 도구 시장은 경쟁이 존재하나 "통합 관리"라는 구체적 니즈가 있음.
2. **높은 ROI**: 버티컬 SaaS 빌더/템플릿 — 금형산업, 병원, 커머스 등 각 산업에서 "범용 SaaS로는 안 된다"는 공통 문제가 반복됨. 산업별 SaaS 템플릿을 제공하는 플랫폼은 반복 매출 구조가 가능.
3. **장기 성장**: 헬스케어 데이터 SaaS — 프리모아에서 고객 확보 완료 사례 존재. 병원 데이터 통계 + 월 구독 모델은 의료 디지털화 트렌드와 맞물려 장기 성장 가능성이 높음.
