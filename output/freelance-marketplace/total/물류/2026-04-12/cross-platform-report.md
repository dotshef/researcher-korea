## 3. Top 3 Pain Points

### 🥇 1위: 물류 ERP·택배사 시스템 연동 자동화 (C1, 점수 82)

**Pain 요약**: 기업 내부 ERP(SAP 등)와 외부 택배사(CJ대한통운) 시스템 간 연동이 미비해 현장 담당자가 수동으로 데이터를 입력하고 검증하는 반복 작업이 발생.

**증거 (위시켓 원문)**:
- "SAP ERP와 CJ 대한통운 시스템을 연동하고, 물류 현장 PC에 연결된 바코드 스캐너로 자동화된 수출 검증 처리를 구현" ([#152801](https://www.wishket.com/project/152801/))
- "CJ 대한통운 택배 접수 API 연동으로 택배 접수 및 운송장 출력 자동화. 기존 수동 작업을 바코드 스캔 연동으로 자동화" ([#147499](https://www.wishket.com/project/147499/))

**솔루션 방향**: SAP ERP ↔ 택배사 API 미들웨어 + 바코드 스캔 통합 솔루션. 재사용 가능한 커넥터 제품화 시 반복 수주 가능.

---

### 🥈 2위: 화주-운전자 매칭 앱 (택배/화물 배차) (C2, 점수 78)

**Pain 요약**: 택배 매칭, 화물 배차, 물류 부자재 구매를 통합한 모바일 앱 수요가 5건으로 가장 많음. 화주와 운전자를 연결하고 상하차 관리까지 처리하는 올인원 앱 니즈.

**증거 (위시켓 원문)**:
- "물류사와 화주를 연결하고 운전자가 화물 상하차를 관리하는 Flutter 기반 모바일 앱 개발" ([#123068](https://www.wishket.com/project/123068/))
- "택배(물류) 매칭 및 물류 부자재 구매를 위한 Android, iOS 앱 구축" ([#128097](https://www.wishket.com/project/128097/))

**솔루션 방향**: Flutter 기반 크로스플랫폼 앱으로 화주·운전자·물류사 3자 매칭 플랫폼. 부자재 구매 기능 통합 시 추가 수익원 확보.

---

### 🥉 3위: 물류 통합 백오피스 (WMS/ERP 전환) (C3, 점수 63)

**Pain 요약**: 구글 스프레드시트·수기 운영에서 정식 WMS/ERP로 전환을 원하는 중소 물류·제조업체 수요. 해외 현지 시스템 구축 포함.

**증거 (위시켓 원문)**:
- "물류센터, 구매팀, 영업팀이 동일한 시트에서 필요한 정보를 접근할 수 있도록 구성" ([#138918](https://www.wishket.com/project/138918/))
- "몽골에서 사용될 POS 시스템, 창고관리(WMS), 물류 ERP 등 종합 물류 시스템 구축" ([#38379](https://www.wishket.com/project/38379/))

**솔루션 방향**: 구글 스프레드시트 → WMS 전환을 위한 경량형 SaaS WMS. 해외 현지화(다국어·현지 세금) 지원 시 차별화.

## 6. 결론 및 기회 제언

1. **즉시 수주 가능 영역**: SAP ERP ↔ CJ대한통운 API 연동 전문성. 위시켓에서 반복 발주 패턴이 확인되어 단기 매출 기회 높음.
2. **성장 잠재력**: 화주-운전자 매칭 앱 — 5건으로 수요 최다. Flutter 전문 팀이 SaaS 형태로 표준화하면 다수 고객 공략 가능.
3. **블루오션**: 크로스보더 물류 + 아마존 API — 역직구 성장과 맞물려 수요 확대 예상. 현재 경쟁이 적고 기술 진입장벽이 있어 선점 가치 있음.
4. **데이터 수집 개선**: 원티드긱스(Playwright 자동화)·프리모아(외부 네트워크 접근 환경) 수집 인프라 보완 필요.
