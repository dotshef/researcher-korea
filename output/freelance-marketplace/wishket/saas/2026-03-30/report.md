## Pain Point Clusters (by opportunity score)

### 1. SaaS 플랫폼 신규 구축 (Score: 73)
위시켓에서 SaaS 키워드의 핵심 수요는 "특정 산업 도메인에 맞춤화된 SaaS 제품을 처음부터 구축"하는 것이다. 쿠팡 셀러 통합관리(5,000~8,000만원), SaaS 마켓플레이스, 금형산업 클라우드 관리 시스템 등 각기 다른 산업이지만 "기존에 적합한 SaaS가 없어서 직접 만든다"는 패턴이 공통이다. 이는 범용 SaaS로는 해결되지 않는 버티컬 니즈가 존재함을 보여준다.
- 예산 범위: 5,000만~8,000만원 (명시된 프로젝트 기준)
- 제품 기회: 버티컬 SaaS 빌더 — 특정 산업(이커머스 셀러, 제조업, 의료) 맞춤 SaaS를 빠르게 구축할 수 있는 로우코드 플랫폼
- 대표 인용:
  > "쿠팡 셀러를 위한 웹 기반 통합 관리 SaaS 솔루션. 매출 데이터 분석 및 운영 효율화를 목표로 하는 플랫폼 구축 프로젝트." — https://www.wishket.com/project/144987/
  > "SaaS 개발사가 서비스를 소개하고 구매자가 견적을 요청할 수 있는 SaaS 마켓플레이스 홈페이지 구축." — https://www.wishket.com/project/140253/
- 관련 소스:
  - [쿠팡 셀러용 통합 관리 SaaS 플랫폼 구축](https://www.wishket.com/project/144987/)
  - [SaaS 개발사/구매자 중개 플랫폼 구축](https://www.wishket.com/project/140253/)
  - [클라우드 기반 SaaS 시스템 관리자 웹 페이지 및 서버 구축](https://www.wishket.com/project/116575/)

### 2. 기존 SaaS 개선/운영 (Score: 30)
이미 운영 중인 SaaS 서비스의 인프라 비용 절감, API 기능 확장, 레거시 유지보수 수요이다. "만드는 것"보다 "유지하는 것"의 비용이 커지는 SaaS 성숙기의 전형적인 문제들이 나타난다. AWS 비용 최적화와 커머스 API 개선은 SaaS 운영사들이 반복적으로 겪는 문제이다.
- 제품 기회: SaaS 인프라 비용 최적화 컨설팅/자동화 도구
- 대표 인용:
  > "인프라 비용 절감을 위한 AWS 아키텍처 다운사이징 및 Java 백엔드 경량화 프로젝트. SaaS 서비스의 운영 비용 최적화 목적." — https://www.wishket.com/project/152055/
  > "SaaS 형 커머스 서비스의 API 개선 및 신규 기능 구현 프로젝트." — https://www.wishket.com/project/104632/
- 언급된 기존 도구: AWS, Java, MSSQL, Classic ASP
- 관련 소스:
  - [인프라 비용 절감을 위한 AWS 아키텍처 다운사이징 및 Java 백엔드 경량화](https://www.wishket.com/project/152055/)
  - [SaaS 형 커머스 서비스 API 개선 및 신규 기능 구현](https://www.wishket.com/project/104632/)
  - [MSSQL + Classic ASP 개발 및 유지보수](https://www.wishket.com/project/131519/)

### 3. AI/특화 SaaS 프론트엔드 (Score: 27)
B2B 업무관리 툴과 LLM 기반 서비스의 프론트엔드 개발 수요이다. 공통적으로 "백엔드/서비스는 있는데 프론트엔드 개발 인력이 부족"한 패턴이다. 초기 스타트업의 B2B SaaS 디자인 니즈는 별도로 주목할 만하다.
- 제품 기회: SaaS 프론트엔드 특화 개발 에이전시 / UI 컴포넌트 라이브러리
- 대표 인용:
  > "일정, 노트, 업무 관리를 통합한 B2B SaaS 업무관리 툴의 시스템 디자인. 초기 스타트업 팀에서 개발 중인 프로젝트." — https://www.wishket.com/project/120480/
- 관련 소스:
