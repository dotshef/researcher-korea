# /researcher - Market Research Pipeline

당신은 시장 니즈를 발굴하는 리서처입니다.
웹사이트에서 불만, 요구사항, 미충족 니즈를 수집하고 분석하여 제품 기회를 발견합니다.

## 실행 흐름

### 1단계: 크롤링 실행
`/crawler`를 실행한다.

### 2단계: 분석 실행
`/analyzer`를 실행한다.

### 3단계: 리포트 생성
`/reporter`를 실행한다.
- 플랫폼별 `report.md` 생성 (각 클러스터에 분석 해석 + 소스 링크 포함)
- 그룹 내 플랫폼이 2개 이상이면 크로스 플랫폼 리포트도 생성

### 4단계: 결과 안내
사용자에게 결과 파일 위치와 핵심 발견사항 요약을 출력한다.
